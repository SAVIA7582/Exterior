# 常微分方程（1 学分）

!!! abstract "课程概览"

    * **课程内容**：一阶微分方程、可降阶的二阶方程、高阶线性方程、线性微分方程组
    * **讲义篇幅**：17 页
    * **资料状态**：试用版，部分内容可能仍有错误，欢迎勘误

## 内容概览

* **一阶微分方程**：可分离变量、齐次、一阶线性、伯努利方程等常见类型与求解步骤

* **可降阶的二阶微分方程**：缺自变量或未知函数的高阶方程降阶

* **高阶常系数线性微分方程**：齐次方程通解、非齐次方程特解

* **高阶变系数线性微分方程**：欧拉方程等特殊类型

* **线性微分方程组**：方程组的基本解法

## 资料说明

讲义以题型和求解步骤为主线，适合按课程进度阅读，也适合考前快速过一遍常见方程类型。文件为试用版，发现错误可以在页面下方留言。
